# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 — 2026-10-08

### 🎉 Features

- Adds `@williamthorsen/build-info`, an initially empty package that will describe which build an app is: its version, commit, build time, environment, and release notes. (#983)
- Adds the `BuildInfo` type with `parseBuildInfo`, `isBuildInfo`, and `serializeBuildInfo`, which check a value against it, and `InvalidBuildInfoError`, which names the first invalid field when parsing or serializing fails. (#985)
- Adds `formatBuildLabel`, which formats a one-line label such as `v0.7.0 · a59f2f8 · 2026-10-08 06:29Z`, and `getCommitUrl`, which returns the URL of the build's commit when its repository is on GitHub. (#985)
